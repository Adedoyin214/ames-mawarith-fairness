# PCIED 2023 — Source Estate Cases

Original 20-case dataset from Project PCIED 2023, Jāmi'at al-Ḥikmah (Al-Hikmah University), Ilorin. This is the raw source data behind Project 1 (engine validation against these 20 cases) and Project 2 (used to calibrate the simulation's estate value ranges).

Transcribed from the original case document for readability — wording and figures are otherwise unchanged from the source.

---
